- **Path Hash**, a new radix-tree-backed data type whose `PH*` commands do exact lookup, longest-prefix matching, and prefix traversal over binary-safe paths.
- **Forkless RDB snapshots**, so [`BGSAVE`](/commands/bgsave/) no longer has to fork, opt-in via `forkless-infrastructure-enabled` and `bgsave-default-method` in [`valkey.conf`](/topics/valkey.conf/).
- **Large sorted sets are backed by a B+ tree** rather than a skiplist, which [`OBJECT ENCODING`](/commands/object-encoding/) reports as `btree`.
- **[ACL](/topics/acl/) roles**: named, reusable sets of selectors managed with `ACL SETROLE`, assigned to users with `role:<name>`.
- **Server-side hot key detection** via `HOTKEYS GET`, plus optional replication throttling that slows writers instead of letting a lagging replica drop into a full sync.
