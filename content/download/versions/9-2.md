- **Path Hash**, a new data type that finds the most specific matching path in one command, for request routing, autocomplete, and LLM inference caches.
- **[Forkless snapshots](/topics/forkless/)**: when enabled, background saves and replica full syncs can run without forking, avoiding the extra memory a fork can use under heavy write traffic.
- **Large sorted sets are backed by a [B+ tree](/blog/from-skiplist-to-b+tree/)**, with up to 43% less memory overhead per member.
- **[ACL](/topics/acl/) roles** let you define a permission policy once and share it across users, and a change to the role applies to all of them at once.
- **Built-in [hot key detection](/topics/hotkeys/)** shows which keys get the most traffic.
