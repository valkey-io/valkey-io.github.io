{%- endcomponent og_card.card %} {# The card's text layout. The browser cannot be told "wrap, but never leave one word on the last line, and never use more than two lines", so the template sets the lines and the browser draws them unwrapped. Widths come from Open Sans's advance widths in _data/og-card/open-sans-400.json, written by build/og-card-widths.py, and any character not in it counts as 1em. Without kerning, the sum runs up to about 2% wider than the browser draws, so lines come out a little short of their limits, never over them. All lengths are in % of the card's width, 12px each, measured in the background's own 16:9 frame, 56.25 tall. The card shows its bottom 52.5 (630px): it crops 3.75 (45px) off the top, which sass/css/og-cards.scss takes off every position. Text starts 4.44 across. The heading's first baseline is at 16.78 (29.83% of the frame's height) and no baseline goes below 33.75 (60%). The heading is at most 6.11; the subheading is at most 0.642 of the heading, with its first baseline 1.204 heading sizes below the heading's last. Lines are 1.1 sizes apart. Each line has two limits, read at its bottom edge: a soft one, where text wraps by default, and a hard one it may run to when that avoids a third line or a one-word last line. Both stay off the wave in the background: the soft one left of its dust, the hard one left of its bright core. The tables give the right edge (% of width) allowed below each height (% of height), measured from default-bg.webp. #} {# Each word's width in em, "|"-separated, then the whole text's width last. #} {% component og_card.widths(text) -%} {%- set glyphs = load_data(path="_data/og-card/open-sans-400.json") -%} {%- set out = "" -%} {%- set total = 0 -%} {%- set words = 0 -%} {%- set w = 0 -%} {%- for word in text | split(pat=" ") %}{% if word %} {%- set_global w = 0 -%} {%- for c in word | split(pat="") %}{% if c %}{% set_global w = w + glyphs[c] | default(value=1) %}{% endif %}{% endfor -%} {%- set_global out = out ~ w ~ "|" -%} {%- set_global total = total + w + (glyphs[" "] if words else 0) -%} {%- set_global words = words + 1 -%} {%- endif %}{% endfor -%} {{ out }}{{ total }} {%- endcomponent og_card.widths %} {# The right edge, % of the card's width, the wave allows at a height, % of its height. #} {% component og_card.edge(y, edge) -%} {%- if edge == "dust" -%} {%- set table = [[32, 63], [38, 58], [45, 55], [50, 49], [54, 48], [60, 40], [101, 38]] -%} {%- else -%} {%- set table = [[22, 85], [26, 82], [30, 78], [34, 74], [38, 69], [42, 64], [46, 59], [50, 54], [54, 51], [58, 48], [62, 45], [101, 44]] -%} {%- endif -%} {%- set x = 0 -%} {%- for row in table %}{% if x == 0 and y < row | first %}{% set_global x = row | last %}{% endif %}{% endfor -%} {{ x }} {%- endcomponent og_card.edge %} {# The widths, in em at size f, of the lines with first baseline `base`, each read at the line's bottom edge: "soft1|hard1|hard2".
