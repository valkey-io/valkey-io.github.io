A module menu file can add topics to a core section ("section: ") or add a new section ("id: ..."), optionally placed after a core section ("after: "). Module files are merged in the order given by config.extra.nav_modules. The menu is lenient: it leaves out what doesn't fit instead of failing the build. Topics that don't exist, module entries for unknown sections, and entries without a topic are skipped. Topics and commands that aren't in the menu are still reachable from the topic index and the command reference. Components can't see `config`, so they take `config.extra` as `extra`.
